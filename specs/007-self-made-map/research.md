# Research: 007 자체 제작 맵

## R1. 성능 예산의 측정 방법과 기준선 (spec "성능 예산")

- **측정 도구**: `tests/bench/perf-scene/perf-scene.spec.ts` (`npx playwright test -c tests/bench/perf-scene --project mobile --trace off`).
  페이지 시작 전에 WebGL2의 `draw*`·`bindFramebuffer`·텍스처 업로드를 감싸 프레임마다 센다. 기본 프레임버퍼에 그린 것이 본 패스,
  다른 프레임버퍼(그림자 맵)에 그린 것이 그림자 패스다. 앱 코드나 테스트 훅을 고치지 않으므로 프로덕션 빌드에도 같은 방법을 쓸 수 있다.
  - 시점: 테마마다 새 방의 스폰 시점(모델이 다 오고 3초 뒤), 경기장 입구를 밟은 뒤 시작 칸 시점. 4초 동안 프레임 중앙값.
  - 20명: 카페 경기장에서 페이지를 가짜 참가자 격자 밖으로 옮긴 뒤 `real.mjs`(`SPREAD=1 BUILD=1`) 19명. 먼저 서 있기만 하고(대조군),
    그다음 각자 앞 칸에 흙 블록을 초당 4번(`TUNING.blockRate`) 놓고 부순다. 10초 동안 잰다.
  - 텍스처 메모리는 어림값이다: 텍셀당 4바이트, 밉맵 제외, 압축 텍스처는 올린 바이트. 그림자 맵과 렌더 타깃도 들어간다.
- **4G 첫 로드**: `tests/e2e/perf.spec.ts` 그대로(판례 2026-11-09-perf-4g). `npm run build` 뒤 모바일 프로젝트.

### 기준선에서 본 것 (007이 고칠 것)

- **그림자 패스가 본 패스보다 크다**: 도서관 스폰 47 대 16, 51.5k 대 9.4k. 그림자 카메라가 테마 경계 전체를 덮어 화면 밖 가구도 그리고,
  책장 모델이 메시 여러 개로 나뉘어 있다. 예산 "그림자 ≤ 본 패스"는 지금 도서관·정원(드로우콜·삼각형)과 카페 스폰(삼각형 13.4k 대 5.5k)에서 넘는다.
- **경기장에 있을 때 방을 그린다**: 경기장 시점의 그림자 패스가 방 스폰과 같은 값(도서관 41/45k)이다. 경기장은 보이지 않는 방 가구의
  그림자를 그리고, 반대로 그림자 카메라가 테마 경계에 맞춰져 있어 경기장(x 20~44) 블록에는 그림자가 지지 않는다(FR-013).
- **블록 변경 비용은 이 환경에서 보이지 않는다**: 19명이 초당 76번 바꿔도 서 있을 때와 긴 작업(4221 대 4402ms)·프레임 중앙값(200 대 200ms)이
  측정 오차 안이다. 소프트웨어 WebGL은 한 프레임이 200ms라 그 사이의 변경이 한 번의 렌더로 묶이고 렌더 비용이 나머지를 덮는다.
  그래도 `Arena.tsx`는 블록 수가 바뀔 때마다 `key={blocks.length}`로 인스턴스 메시를 새로 만들고 충돌체 목록 전체를 다시 맞춘다(코드로 확인).
  프레임이 짧은 실제 휴대폰에서는 변경마다 이 비용을 낸다. 예산 줄은 그대로 두고 판정은 기준 기기 `?perf` 측정과 함께 본다.
- **텍스처가 늘어난다**: 살아 있는 텍스처가 19명이 나가고 새 19명이 들어와 블록을 바꾸는 동안 127에서 237로 늘었다(메모리는 0.06MB). 참가자 교체 때문인지 블록 때문인지는 이 측정으로 가를 수 없다. 작은 텍스처가 해제되지 않는지
  plan에서 원인을 본다(이름표·피해 숫자 후보).
- 프레임 시간: 소프트웨어 WebGL이라 휴대폰 값이 아니다(004 T056). 회귀 비교에만 쓴다.

### 결정

- **Decision**: 예산 표의 GPU 무관 항목은 perf-scene 값으로 판정하고, 프레임은 미리보기 `?perf` 표시로 기준 기기에서 판정한다.
- **Rationale**: 드로우콜·삼각형·텍스처는 하드웨어와 무관해 컨테이너·CI에서도 실제 값이다. 앱 코드 훅 없이 세므로 측정이 앱을 바꾸지 않는다.
- **Alternatives**: `renderer.info`를 테스트 훅으로 내보내기: 개발 빌드에만 있고(헌법 IV) 프로덕션을 잴 수 없다.
  CDP CPU 감속으로 저사양 흉내: GPU가 소프트웨어라 휴대폰과 상관이 없다.
