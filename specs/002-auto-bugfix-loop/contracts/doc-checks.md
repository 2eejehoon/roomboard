# 문서 검사 계약 (`scripts/check-docs.mjs`)

입력: base 커밋, head 커밋, PR 라벨. 출력: 위반 목록(0개면 통과). 각 위반 문구는 고치는 방법을 담는다(FR-045).

| 검사 | 대상 | 실패 조건 | 문구(요지) |
|---|---|---|---|
| D1 판례 필수 | 헌법, `specs/**/spec.md`, `specs/**/plan.md` 변경 | 새 `docs/precedents/*.md` 없음, `no-precedent` 라벨 없음 | "결정을 바꿨다면 `docs/precedents/YYYY-MM-DD-<slug>.md`를 추가하세요. 결정이 안 바뀐 오타 수정이면 `no-precedent` 라벨을 붙이세요." |
| D2 판례 불변 | base에 있던 판례 파일 | diff가 맨 끝 `대체됨: <파일>` 한 줄 추가가 아님 | "머지된 판례는 고칠 수 없습니다. 새 판례를 쓰고 옛 판례에는 `대체됨: <새 파일>` 한 줄만 추가하세요." |
| D3 판례 형식 | 판례 파일 | 이름이 `YYYY-MM-DD-<slug>.md`가 아님, 필수 항목(날짜·대상·출처·대체한 판례·결정·이유·검토한 대안) 누락, 40줄 초과 | 누락 항목 이름, 넘은 줄 수 |
| D4 판례 목록 | `docs/precedents/README.md` | 목록에 없는 파일 또는 없는 파일을 가리키는 행 | 추가·삭제할 행 |
| D5 길이 상한 | 헌법 "문서 구조" 표에 있는 문서 | 상한 초과 | "<파일>이 <n>줄로 상한 <m>줄을 넘었습니다. 역할이 다른 내용을 <제안 문서>로 옮기세요." |
| D6 Clarifications 금지 | `specs/**/spec.md` | `## Clarifications` 제목 존재 | "Q&A를 본문(FR 등)에 반영하고 판례로 옮긴 뒤 이 절을 지우세요." |

- 길이 상한 값은 헌법 표를 직접 파싱한다. 상한이 "없음"인 행은 검사하지 않는다.
- 첫 도입 PR에서 기존 문서가 이미 위반하면 그 PR에서 함께 고친다(예외 목록을 두지 않는다).
