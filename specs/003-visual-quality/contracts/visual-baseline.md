# Contract: 기준 화면 (FR-013)

`tests/e2e/visual.spec.ts`가 찍는 화면이다. 파일 이름은 `<화면>-<크기>.png`, 크기는 `desktop`(1280×720),
`phone`(412×839, Pixel 7). CI는 `test-results/visual/`을 결과물 `visual`로 올린다.

| 화면 | 상태 | 자동 검사 |
|------|------|-----------|
| `list` | 방 3개 이상(테마별 하나) | 가로 스크롤 없음, 터치 크기, 대비 |
| `list-empty` | 방 없음(응답을 빈 목록으로 바꿈) | 방 만들기 안내 보임 |
| `create` | 빈 폼, 테마 선택 보임 | 터치 크기, 대비 |
| `room3d-<테마>` | 테마별, 스폰 위치, 3D 로딩 끝 | 아바타 밝기(SC-002), 그림자(FR-002), 경계 밖 단색 없음(FR-001) |
| `room3d-loading` | 3D 에셋 응답을 잡아 둔 상태 | 진행률 보임 |
| `room2d` | WebGL 끔 | 대비, 가로 스크롤 없음 |
| `admin` | 신고 1건 | 대비 |
| `gone` | 삭제된 방(410) | 목록으로 가는 링크 |

- 3D 화면은 픽셀을 비교하지 않는다(research R6). 모습 판정은 운영자가 한다.
