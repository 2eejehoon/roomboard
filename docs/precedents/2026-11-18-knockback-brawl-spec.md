## 결정

- 004는 "직접 지은 블록 경기장에서 맨손으로 싸우는 넉백 난투" 스펙이다. 장르 재미만 가져온 오리지널 설계다.
  enhancement-spec이 004 후보로 둔 것 중 때리기는 이 스펙이 맡고, 혼자 하는 상호작용·업기·말걸기·방꾸미기·R16 지연 로딩은 일정 없이 남긴다.
- 경기장과 평화 구역(FR-013·FR-014): 지금의 방 공간 전체가 평화 구역이고, 경기장은 방 옆에 떨어진 블록 섬이다. 입구·출구로 오간다.
- 경기장 저장(FR-018·FR-037): 경기장·판의 단위는 001 채널이다. 지은 경기장은 저장하지 않고, 채널이 비면 기본 경기장으로 돌아간다. 그동안 보이는
  경기장은 사용자 콘텐츠라 방 신고로 알리고, 관리자가 경기장을 보지 않고 기본 경기장으로 되돌린다(새 관리자 동작, FR-040, PR #75 리뷰).
- 떨어뜨리기 승리 조건(FR-026): 목숨 3개(초기값), 다 잃으면 탈락해 다시 서지 않고 평화 구역에서 관전, 마지막 한 명 승리. 판 도중에는 참가자만 경기장에 들어간다.
  판은 경기장에 있는 사람만 시작하고, 제한 시간(초기값 5분)이 지나면 목숨·피해 %로 순위를 정해 끝낸다(FR-025·FR-025a, PR #75 리뷰).
- 2D 화면(FR-033): 경기장을 옆에서 본 단순한 그림 위에서 3D와 같이 싸우고, 스크린 리더용 글 기록을 함께 둔다.
- 방향 틀기(FR-028)는 날아가기 시작할 때 한 번 정하고, 공중 점프·복귀기·벽 충돌은 새 궤적의 시작으로 전한다(FR-029·FR-032).
  블록 윗면에 내려앉으면 착지로 궤적이 끝나고, 벽 규칙(튕김·뚫림)은 옆면·아랫면에만 쓴다. 기본 경기장은 돌 블록이다(FR-016·FR-019).
  넉백을 시작점·방향·세기만 보내고 모든 화면이 같은 공식으로 계산한다는 네트워크 원칙을 지키기 위해서다.
- 타격 정지는 판정의 일부로, 넉백 궤적은 타격 정지가 끝난 시각에 시작한다(FR-020·FR-024, PR #75 리뷰).
- 보이는 모습(FR-030a)은 판정과 떨어진 모습 목록 한 곳에서 정해, 나중에 디자인만 바꿀 수 있게 한다(운영자 질문, 2026-11-18).
- 한 판의 인원 상한(SC-006)은 정하지 않고, plan에서 가짜 클라이언트 측정으로 정한다(spec "열린 질문").

## 이유

- 방 옆 경기장: 기존 이동·채팅·가구 배치를 건드리지 않고, 싸우기 싫은 사람은 그냥 방에 있으면 된다.
- 저장 안 함: 저장하면 오래 남는 사용자 콘텐츠가 되어 되돌릴 사람과 시점을 더 정해야 한다. 저장하지 않아도 방이 열린 동안은
  모두가 보므로 신고·관리자 되돌리기는 둔다(헌법 제품 제약). 블록 모양은 글자 욕설 필터로 거를 수 없어 필터는 두지 않는다.
- 블록 놓을 칸은 "보는 방향 바로 앞 칸 + 높이 세 가지"로 정해, 칸을 가리킬 수 없는 휴대폰·2D 옆 화면도 같은 버튼으로 짓는다(FR-015a).
- 목숨제: 끝이 분명해 "한 판 더"가 쉽고, 동점은 함께 탈락할 때와 제한 시간 종료 때 남은 사람끼리 목숨·%가 같을 때뿐이고 같은 순위로 처리한다(FR-025a·FR-027).
- 옆에서 본 그림: 넉백 각도와 낙하가 옆 모습에서 그대로 보인다. 글만으로는 사실상 싸울 수 없다.

## 검토한 대안

- 방 전체를 경기장으로 / 방 만들 때 난투 방 선택: 기존 방 꾸밈과 충돌하거나 방 종류가 늘어난다. 기각.
- 경기장을 방에 저장 / 판이 끝날 때 초기화: 앞의 것은 UGC 관리 부담, 뒤의 것은 자유 난투 중 지은 것이 갑자기 사라진다. 기각.
- 시간제, 둘 다 고르기: 동점 처리나 화면·테스트가 두 배. 기각. 제한 시간은 승리 조건이 아니라 판이 끝나는 것을 보장하는 상한으로만 둔다.
- 2D는 글 기록과 버튼만 / 관전만: 2D 이용자가 놀이에 끼지 못한다. 기각.
- 날아가는 도중에도 방향 틀기: 다른 화면이 궤적을 다시 계산할 수 없어 SC-003(착지 위치 한 칸 이내)이 깨진다. 기각.
