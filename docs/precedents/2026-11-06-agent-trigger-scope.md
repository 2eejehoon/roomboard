# 수정 에이전트는 서비스 봇 이슈에서만 자동 실행

- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/spec.md FR-020
- 출처: 002 clarify, 이 PR
- 대체한 판례: 없음

## 결정

서비스 봇이 만든 버그 이슈(새로 생김·재발)에서만 에이전트가 자동 실행된다. 사람이 연 이슈는 쓰기 권한자가 "에이전트 실행" 표시를 붙여야 실행된다.

## 이유

공개 저장소라 누구나 이슈를 열 수 있으니, 사람이 연 이슈로 에이전트를 조종하거나 비용을 태우는 것을 막는다(헌법 VII).
클라이언트 리포트도 위조할 수 있으므로 봇 이슈만으로는 충분하지 않다. 그래서 클라이언트 리포트 이슈는 배포 빌드의 실제
소스 위치로 해석되고 3건 이상일 때만 자동 실행한다(FR-015). 에이전트 실행에 고정 횟수 상한이 없으므로(판례
2026-11-06-agent-budget) 이 조건과 이슈 상한(FR-013)이 비용 방어선이다.

## 검토한 대안

운영자 라벨 이슈만(자동 루프에 사람 단계 추가), 모든 새 이슈(악용·비용 위험).
