# 수정 에이전트가 브랜치를 직접 만들고 이름을 결과로 돌려준다

- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/contracts/github.md 에이전트 PR 규칙
- 출처: T020 2차 시험(이슈 #9), 이 수정 PR
- 대체한 판례: 없음

## 결정

에이전트가 `agent/issue-<n>-<slug>` 브랜치를 만들어 push하고, 구조화된 결과의 `branch`에 이름을 담는다. 워크플로는
브랜치가 `agent/issue-<이 이슈 번호>-`로 시작하고 원격 SHA가 이번 실행의 로컬 브랜치와 같을 때만 Claude App 토큰으로
PR을 연다(다른 이슈 브랜치나 이전 실행이 남긴 브랜치 차단). 수정했는데 PR을 못 만들면 `agent:needs-human`.

## 이유

이 방식(프롬프트로 실행)에서는 액션의 `branch_name` 출력이 비어 있어, 2차 시험에서 수정과 push는 성공했지만 PR이
만들어지지 않았다.

## 검토한 대안

액션이 브랜치를 만들게 하기(이 실행 방식에서는 만들지 않음), 에이전트가 PR까지 열기(PR 권한 도구를 에이전트에 줘야 함).
