# 에이전트 실행은 사용량 예산이 남는 만큼

- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/spec.md FR-024, 헌법 원칙 VII
- 출처: 002 clarify, 이 PR
- 대체한 판례: 없음

## 결정

에이전트 실행 횟수는 고정하지 않고 운영자 계정의 사용량(토큰) 예산이 남아 있는 동안 실행한다. 예산이 바닥나면 대기열에 두고 회복되면 오래된 순으로 실행한다. 실행 1회당 상한과 같은 이슈 재시도 상한(2회)은 폭주 방지로 둔다. 헌법 VII의 "실행 횟수 상한"을 "비용 상한(사용량 예산) + 폭주 방지 상한"으로 바꿨다.

## 이유

운영자 요청("토큰이 있는 만큼"). 예산 자체가 비용 상한 역할을 한다.

## 검토한 대안

하루 5회·2회·20회 고정 상한.
