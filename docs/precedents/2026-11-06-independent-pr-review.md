# 모든 PR에 독립 리뷰 에이전트, 모델은 운영자 설정대로

- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/spec.md US7, FR-060~065, research R2·R10
- 출처: 운영자 요청(머지 검토 자동화), 에이전트 워크플로 PR
- 대체한 판례: 없음

## 결정

모든 저장소 브랜치 PR을 별도 리뷰 에이전트가 새 세션에서 리뷰하고, 차단 지적이 있으면 `ai-review` 검사가 실패한다. 리뷰
에이전트는 댓글과 검사만 남기고 머지는 사람이 한다. 에이전트별 모델은 운영자의 역할별 설정(수정·리뷰·문서 정리 opus, 장치
sonnet)을 따른다.

## 이유

지금까지 작성자(에이전트)와 검토자가 같았다. 서비스 코드가 들어가기 전에 작성 맥락 없는 검토가 필요하다. 모델 선택은 운영자가
정한 설정이 우선이다.

## 검토한 대안

리뷰어를 다른 모델로 강제(운영자 설정과 충돌해 기각), 자동 머지까지(헌법 VII 개정 필요, 리뷰 품질을 본 뒤 다시 판단).
