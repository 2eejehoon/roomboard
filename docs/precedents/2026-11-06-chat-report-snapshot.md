# 채팅은 저장하지 않고 신고된 메시지만 스냅샷

- 날짜: 2026-11-06
- 대상: specs/001-realtime-room-board/spec.md FR-041, 신고 엔티티
- 출처: PR #2, clarify
- 대체한 판례: 없음

## 결정

채팅은 휘발성으로 두고, 신고된 메시지 내용만 신고와 함께 저장해 관리자가 검토·처리 완료한다. 지울 채팅 원본은 없다.

## 이유

저장량과 개인정보 위험을 최소로 하면서 채팅 악용에 대응한다.

## 검토한 대안

최근 채팅 기록 보관(저장·검열 범위 증가), 방만 관리자 삭제(채팅 악용 대응 약함).
