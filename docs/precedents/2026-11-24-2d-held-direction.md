# 2D 방향 틀기는 "방향 잡기" 순환 버튼

- 날짜: 2026-11-24
- 대상: `specs/004-knockback-brawl/spec.md` FR-033(FR-028·FR-004), tasks T061
- 출처: PR #98 리뷰(2D `move`가 `d`를 보내지 않아 2D 참가자는 방향 틀기를 못 함)
- 대체한 판례: 없음

## 결정

2D 화면에 "방향 잡기" 버튼 하나를 둔다. 누를 때마다 없음 → 왼쪽 → 오른쪽 → 앞 줄 → 뒤 줄 → 없음으로 바뀌고, 바꿀 때 제자리 `move`에
그 방향을 `d`로 실어 보낸다. 칸 이동 버튼의 `move`도 고른 방향을 계속 싣는다. 서버는 그대로(`move.d ?? null`)다.

## 이유

- 2D는 버튼을 누를 때만 `move`를 보내므로 "누르고 있는 동안"을 그대로 옮길 수 없다. 고른 방향을 계속 들고 있게 하면 맞기 전에 미리 정해 둘 수 있다(FR-028 "맞기 전부터 누르고 있던 방향").
- 버튼 하나라 화면이 늘지 않고, 기존 블록 종류·높이 버튼과 같은 모양(순환)이라 익히기 쉽다.

## 검토한 대안

- 좌·우·앞·뒤 버튼을 누르고 있는 동안만 `d`: 2D 버튼은 클릭이라 맞는 순간에 누르고 있기 어렵고, 키보드·스크린 리더 이용자에게 불리하다.
- 방향 버튼 네 개(라디오): 버튼 줄이 하나 더 늘어난다. 순환 하나로 충분하다.
