- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/plan.md 구현 순서
- 출처: 002 plan

## 결정

002 구현은 판례·문서 구조 CI 검사(US5) → 에이전트 워크플로(US2) → 실수 집계(US4) → 문서 정리(US6) → 오류 수집(US1·US3) 순으로 한다.

## 이유

US5는 서비스 없이 만들 수 있고, 만드는 즉시 헌법 Governance 규칙이 문서가 아니라 검사가 된다(원칙 VI). 수집은 001 서비스가 있어야 동작한다.

## 검토한 대안

스펙 우선순위(P1 수집·에이전트) 순서 — 001 서비스가 없어 검증할 수 없어서 기각.
