# 사용자 버그 신고는 운영자 검토 후 이슈화

- 날짜: 2026-11-06
- 대상: specs/002-auto-bugfix-loop/spec.md FR-014, US3
- 출처: 002 clarify, PR #4

## 결정

사용자 버그 신고 원문은 비공개로 30일 보관 후 삭제한다. 운영자가 관리자 화면에서 요약을 써서 "이슈로 만들기"를 누르면 요약만 담긴 공개 이슈가 생기고 에이전트가 실행된다.

## 이유

공개 이슈로 사용자 원문·개인정보가 새는 것과 장난 신고로 에이전트가 도는 것을 막는다(헌법 II, VII).

## 검토한 대안

메타데이터만 자동 이슈화(정보 부족), 사용자 신고 v1 제외(범위 축소).
