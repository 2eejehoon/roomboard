# 문서 구조 표를 경로 패턴으로 다시 씀 (헌법 1.1.1)

- 날짜: 2026-11-06
- 대상: 헌법 문서 구조 절
- 출처: 002 US5 구현 PR
- 대체한 판례: 없음

## 결정

문서 구조 표의 첫 열을 경로 패턴(`*`, `**`)으로 바꾸고, 여러 행이 맞으면 위의 행을 따른다는 규칙을 넣었다.
판례 목록 `docs/precedents/README.md`와 `.claude/skills/**`는 상한 없음으로 명시했다. 그 밖의 상한 값은 그대로다.

## 이유

문서 검사 스크립트(002 US5)가 표를 직접 읽어야 상한이 두 곳에 적히지 않는다. 판례 목록은 판례 수만큼 늘어나는
색인이라 판례 하나의 40줄 상한을 적용하면 곧 위반이 된다. 스킬은 Spec Kit이 생성한 긴 파일이 있어 상한을 두지 않는다.

## 검토한 대안

기존 자유 서술("`plan.md`, `research.md` 등")을 스크립트가 해석 — 규칙이 모호해서 기각.
