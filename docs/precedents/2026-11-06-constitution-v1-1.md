# 헌법 v1.1.0: 재발 방지, 자동화 경계, 판례 제도, 문서 구조

- 날짜: 2026-11-06
- 대상: 헌법 원칙 VI·VII, 문서 구조, Governance
- 출처: PR #4
- 대체한 판례: 없음

## 결정

원칙 VI(재발 방지는 구조로: 구조 > 타입 > 린트 > 테스트 > 문서, 문서 지속 정리), 원칙 VII(버그 리포트 → 이슈 → 에이전트 → PR 자동화 허용, 외부 입력 불신, 머지는 사람, 공개 이슈에 개인정보 금지)을 추가했다. 본문은 최신만 두고 히스토리는 판례로 남기는 규칙, 문서별 역할과 길이 상한을 정했다(기계가 읽는 `contracts/*.yaml`은 스키마 린트로 검사하므로 상한 없음).

## 이유

자동 버그 수정 루프와 지속적인 문서 정리를 도입하되, 문서 비대화와 자동화의 보안·개인정보 위험을 막기 위해.

## 검토한 대안

개정 이력을 헌법 본문(Sync Impact Report)에 누적 — 본문이 비대해져서 기각. 판례 번호 순번(NNNN) — 동시 PR 충돌로 날짜 기반 채택.
