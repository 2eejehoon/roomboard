# 방·가구 에셋은 Kenney 대신 Quaternius

- 날짜: 2026-11-07
- 대상: specs/001-realtime-room-board/research.md R13, tasks.md T048·T067
- 출처: 001 US1 U3 PR (T045~T048)
- 대체한 판례: 없음

## 결정

방·가구 3D 에셋을 Kenney가 아니라 Quaternius 팩(CC0)에서 가져온다. 캐릭터(Quaternius)와 HDRI(Poly Haven)는 그대로다.
파일은 quaternius.com 팩 페이지가 연결한 Google Drive 폴더에서 받고, 받은 원본과 가공 방법을 `public/assets/CREDITS.md`에 적는다.
운영자가 승인했다.

## 이유

kenney.nl이 클라우드 세션의 요청에 403을 돌려준다(봇 차단). 우회는 하지 않는다(헌법 VII의 정신, 출처 증명).
Quaternius는 캐릭터와 같은 저폴리 화풍이고, 라이선스 파일(CC0 1.0)이 팩 안에 들어 있어 파일별 출처를 증명할 수 있다.

## 검토한 대안

- 운영자가 Kenney zip을 받아 올리기: 사람 손이 필요하고 T048이 그동안 막힌다.
- Poly Haven 모델: 사실적인 텍스처가 커서 테마당 5MB 목표를 넘기 쉽고 캐릭터와 화풍이 다르다.
- GitHub 미러: 출처를 증명할 수 없다.
