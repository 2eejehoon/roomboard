# 2D 채팅은 숨긴 목록이 닉네임·내용만 읽어 준다

- 날짜: 2026-11-09
- 대상: specs/001-realtime-room-board/contracts/screens.md S3(2D 채팅), `src/client/room/ChatPanel.tsx`
- 출처: 001 US7 화면 PR #39 리뷰
- 대체한 판례: 2026-11-09-chat-panel(읽어 주는 영역 부분만)

## 결정

- 보이는 메시지 목록은 `aria-live`를 두지 않는다. 메시지마다 신고 버튼이 있다.
- 2D에서는 같은 메시지를 "닉네임: 내용"으로만 담은 숨긴 목록(`VisuallyHidden` 안의 `<ul aria-live="polite">`)이 새 메시지를 읽는다.
- 최근 100개, 3D의 `<details>`는 2026-11-09-chat-panel 그대로다.

## 이유

신고 버튼(T091)이 읽어 주는 목록 안에 있으면, 새 메시지마다 "○○ 님 메시지 신고"까지 따라 읽힌다(헌법 V). 숨긴 목록은 읽힐 문구만 담으니 "새 메시지만 읽는다"는 원래 뜻이 그대로 지켜진다.

## 검토한 대안

- 버튼을 목록 밖에 따로 두기: 어느 메시지의 신고인지 키보드로 찾기 어렵다.
- 마지막 메시지 하나만 담은 live 영역: 메시지가 빨리 연달아 오면 앞의 것이 덮여 읽히지 않을 수 있다.
