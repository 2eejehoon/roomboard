# 에셋은 CC0 또는 생성 스크립트로 직접 만든 것 (헌법 2.1.0)

- 날짜: 2026-11-27
- 대상: 헌법 제품·품질 제약(에셋), specs/004-knockback-brawl/spec.md FR-038·Assumptions, specs/006-skills-combos/spec.md FR-030, specs/003-visual-quality/spec.md FR-010·Assumptions, `public/assets/CREDITS.md` 머리말
- 출처: 운영자 결정(2026-11-27, 005 캐릭터): "캐릭터를 완성도 있게 먼저, 디자인 퀄리티와 성능이 굉장히 중요하다. 시간이 걸려도 과감하게 자체 제작으로 간다."
  같은 날 정정: 유료 생성 도구(Meshy Pro)를 쓰지 않고 돈을 쓰지 않는 방법만 쓴다.
- 대체한 판례: 없음(2026-11-07-assets-quaternius의 Quaternius 에셋은 CC0라 그대로 유효)

## 결정

- 에셋은 CC0이거나 우리가 직접 만들어 권리를 가진 것(자체 제작)만 쓴다.
- 자체 제작은 저장소의 생성 스크립트(헤드리스 Blender Python, 코드 지오메트리·절차적 텍스처 등)로 다시 만들 수 있어야 한다.
  `CREDITS.md`에 스크립트 경로와 다시 만드는 명령을 적는다. 스크립트가 곧 출처 증명이다.
- 생성 AI 서비스의 결과물, CC BY 등 표시 라이선스, 권리가 불분명한 것은 쓰지 않는다.
- 자체 제작도 기존 작품(게임·캐릭터·브랜드)의 이름·생김새를 흉내 내지 않는다.
- 캐릭터 몸과 기술 동작(004·006)은 005 스펙(`specs/005-own-characters/`, 별도 PR, 브랜치 `claude/005-own-characters`)이 맡는다.
- MINOR(2.1.0): 원칙은 그대로이고 제품 제약의 허용 범위를 넓히고 기록 규칙을 더했다.

## 이유

- 무료 팩(Quaternius, KayKit 등)은 화풍과 동작 목록을 우리가 정할 수 없다. 004·006 기술의 선딜·후딜 포즈와 오리지널 스타일이 필요하다.
- 스크립트로 만들면 누구든 같은 결과를 다시 만들 수 있고(헌법 I), 삼각형·본·텍스처 크기를 코드에서 직접 통제한다(성능 예산).
- 생성 AI 결과물은 요금제마다 권리가 다르고(무료는 CC BY인 곳도 있다) 다시 만들 수 없다. 운영자가 유료 결제를 하지 않기로 했다.

## 검토한 대안

- CC0만 유지하고 무료 팩을 고르기(KayKit 비교 시안, 이전 005 세션): 운영자가 자체 제작을 골라 기각.
- 유료 생성 도구(Meshy Pro) 결과물 허용: 결제하지 않기로 해 기각. 재현성도 없다.
- CC BY 등 표시 라이선스 허용: 파일마다 표시 의무가 생겨 기각.
