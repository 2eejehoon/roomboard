# 관리자 인증은 비밀 토큰

- 날짜: 2026-11-06
- 대상: specs/001-realtime-room-board/spec.md FR-042
- 출처: PR #2, clarify
- 대체한 판례: 없음

## 결정

관리자는 배포 비밀값 `ADMIN_TOKEN`을 관리자 화면에 입력해 인증한다. 실패에도 요청 횟수 제한을 건다.

## 이유

로그인 없는 서비스(원칙 II)에서 개인정보 없이 가장 단순하게 관리자를 구분할 수 있다.

## 검토한 대안

Cloudflare Access(설정 부담), 관리자 화면 없이 DB 직접 처리(운영 불편).
