# 욕설 필터는 붙여 쓴 복합어 오탐을 감수

- 날짜: 2026-11-07

## 결정

필터는 붙여 쓴 욕설(`씨발놈아`)을 잡는 쪽을 택한다. 대가로 붙여 쓴 복합어 안의 우연한 일치(`장염병원` → `장**원`)는 감수한다.
공백을 건너뛰는 매치는 낱말 처음에서 시작해 낱말 끝에서 끝나야 하고, 3음절 이상 금칙어에만 조사·어미가 붙을 수 있다.
오탐은 운영 중 신고를 보고 목록을 고쳐 줄인다.

## 이유

리뷰마다 규칙을 바꾸면 오탐이 다른 곳으로 옮겨 갈 뿐이었다(`몇 시 발표` → `포도 씨 발라` → `몇 시 팔아` → `장염병원`).
부분 문자열 필터로는 오탐과 누락을 함께 없앨 수 없다(Scunthorpe 문제). 운영자가 이 절충을 승인했다.

## 검토한 대안

- 낱말 경계 요구: 붙여 쓴 욕설을 놓친다.
- 복합어 허용 목록: 끝이 없고 경계만 옮겨진다.
- 형태소 분석기: 번들·CPU 부담이 커서 v1 범위 밖이다.
