# 003 시각 품질: 3D는 아늑한 로우폴리, 화면은 전체를 고르게

- 날짜: 2026-11-11
- 대상: specs/003-visual-quality/spec.md FR-005~FR-009, FR-014
- 출처: 운영자 답변(2026-11-11, "퀄리티가 전반적으로 매우 아쉽다" 후속 질문), 003 스펙 PR
- 대체한 판례: 없음

## 결정

- 3D 그래픽 방향은 아늑한 로우폴리다. 지금의 CC0 에셋 스타일을 유지하고 벽·그림자·조명·색감으로 완성도를 올린다.
- 화면 디자인은 특정 화면을 먼저 고치지 않고 디자인 기준(FR-005~FR-009)을 모든 화면에 고르게 적용한다.
- 아쉬운 점 중 3D 그래픽과 화면 디자인을 003에서 다룬다. 이동할 때 화면 전체가 흰색으로 깜빡이는 현상
  (Claude 모바일 앱 인앱 브라우저)은 001 버그 T107로 따로 다룬다.

## 이유

- 운영자가 세 방향 중 로우폴리를 골랐다. 첫 로딩 5MB와 4G 10초(001 SC-001)를 지키기 가장 쉽다.
- 디자인 질문에는 특정 화면을 꼽지 않았다.

## 검토한 대안

- 사실적 재질·조명: 에셋이 커져 5MB·10초 기준과 부딪힌다.
- 만화풍(외곽선): 가구·아바타 모두 스타일을 바꿔야 한다.
